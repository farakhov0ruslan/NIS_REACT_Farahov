# 🌐 Cyber Zoo 2077 - HW_2

Интерфейс для виртуального Кибер-Зоопарка 2077, где обитают цифровые животные — гибриды биологии и
искусственного интеллекта.

## 📋 Описание проекта

**Cyber Zoo Dashboard** - одностраничное приложение для управления виртуальными питомцами с
киберпанк дизайном. Пользователь может наблюдать за питомцами, менять их характеристики и
настроение, кормить их, повышать уровень и отслеживать системные события.

## ✨ Функциональность

### Основные возможности

- 🔄 **Загрузка питомцев** - асинхронная загрузка с Skeleton Loader
- 🔍 **Фильтрация** - фильтр по видам питомцев (species)
- 🎮 **Управление питомцами**:
    - 🍖 **Feed** - кормление (+20 энергии)
    - ⬆️ **Level Up** - повышение уровня
    - ✨ **Cheer** - улучшение настроения
    - 🔄 **Reset** - сброс до начального состояния
- ⚡ **Автоматическая механика**:
    - Энергия уменьшается каждые 5 секунд (-10)
    - Настроение меняется в зависимости от энергии
    - При energy = 0 питомец становится недоступным
- 📊 **Лог событий** - отслеживание всех действий в боковой панели

## 🎨 Технологии и подходы

### React Hooks

- ✅ **useState** - управление состоянием (pets, loading, filters)
- ✅ **useEffect** - загрузка данных, таймеры, side effects
- ✅ **useReducer** - управление состоянием питомца (4 действия)
- ✅ **useCallback** - мемоизация обработчиков событий
- ✅ **useMemo** - оптимизация фильтрации списков
- ✅ **useRef** - DOM манипуляции, отслеживание значений
- ✅ **useContext** - глобальное состояние для логов
- ✅ **React.memo** - оптимизация рендеринга компонентов

### Кастомные хуки

1. **usePetLifecycle** - управление жизненным циклом питомца
    - Автоматическое уменьшение энергии
    - Изменение настроения
    - Cleanup таймеров

2. **useEventLog** - работа с логами событий
    - Добавление событий с timestamp
    - Очистка логов
    - Типизированный API

### Стилизация (4 подхода)

1. **SCSS** (`global.scss`) - базовая сетка и киберпанк тема
2. **CSS Modules** (`PetCard.module.scss`) - изолированные стили карточек
3. **Inline Styles** - динамические тени в зависимости от настроения
4. **styled-components** (`ActionButton.styled.ts`) - кнопки с градиентами
5. **Material UI** - Drawer, Skeleton, Select, Button и др.

## 🎮 Использование

1. **Загрузка питомцев**
    - При запуске отображается Skeleton Loader (2 секунды)
    - Затем загружаются 8 кибер-питомцев

2. **Фильтрация**
    - Используйте селектор в правом верхнем углу
    - Выберите вид питомца или "All Species"

3. **Управление питомцем**
    - **Feed** - восстановление энергии
    - **Level Up** - повышение уровня
    - **Cheer** - улучшение настроения
    - **Reset** - возврат к исходному состоянию

4. **Лог событий**
    - Нажмите кнопку меню (☰) в правом верхнем углу
    - Просматривайте все действия с timestamp
    - Очистите лог кнопкой "Clear Log"
